🥖 Sistema de Vendas - Padaria

⚙ Funcionalidades Principais ⚙

O sistema foi desenvolvido para auxiliar no gerenciamento de produtos, estoque e vendas de uma padaria por meio de uma interface gráfica simples e intuitiva.

🔍 Funcionalidades disponíveis 🔍

* Cadastro de novos produtos.

* Exibição dos produtos cadastrados.

* Realização de vendas com atualização automática do estoque.

* Remoção de produtos do sistema.

* Cancelamento da última venda realizada.

* Reposição do estoque após o cancelamento de uma venda.

* Consulta do estoque geral.

* Consulta das informações da última venda.

* Busca de produtos pelo nome.

* Verificação de estoque disponível antes da realização da venda.

* Interface gráfica com mensagens de confirmação, alerta e erro.

* Área de suporte e informações do desenvolvedor.

Panorama Geral: O Sistema de Vendas 🥖

O Sistema de Vendas da Padaria foi desenvolvido para facilitar o gerenciamento de produtos, estoque e vendas de uma padaria. A aplicação permite cadastrar produtos, consultar informações, controlar o estoque, realizar vendas, excluir produtos e cancelar a última venda realizada.

O sistema possui uma interface gráfica desenvolvida em Python utilizando a biblioteca Tkinter, tornando sua utilização simples e intuitiva. Todas as operações são realizadas por meio de botões e campos de entrada, permitindo que o usuário execute as ações sem necessidade de utilizar o terminal.

Além disso, o sistema realiza validações de dados, verifica a disponibilidade dos produtos antes das vendas, atualiza automaticamente o estoque após cada operação e apresenta mensagens de confirmação, alerta e erro, proporcionando maior organização e praticidade no gerenciamento dos produtos da padaria.
