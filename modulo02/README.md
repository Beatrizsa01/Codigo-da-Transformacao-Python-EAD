🐍 Projetos Introdutórios - Python

Funcionalidades Principais

Os projetos foram desenvolvidos com o objetivo de apresentar conceitos básicos da linguagem Python por meio de programas simples e interativos.

Funcionalidades disponíveis:

* Entrada de dados utilizando input().
* Exibição de mensagens utilizando print().
* Saudação personalizada ao usuário.
* Exibição da hora atual do sistema.
* Utilização da biblioteca datetime.
* Identificação do tipo de diferentes valores utilizando type().
* Demonstração dos principais tipos de dados do Python.
* Interação básica com o usuário por meio do terminal.

Panorama Geral: Projetos Introdutórios em Python

Os projetos foram desenvolvidos para praticar conceitos fundamentais da linguagem Python, utilizando exemplos simples de entrada, processamento e saída de informações.

Um dos programas solicita o nome do usuário e apresenta uma mensagem de boas-vindas junto com a hora atual do sistema. Para obter o horário, é utilizada a biblioteca datetime, permitindo trabalhar com informações relacionadas à data e hora.

Outro exemplo trabalha com a entrada de dados utilizando input(), solicitando o nome do usuário e exibindo uma saudação personalizada.

Também foi desenvolvido um exemplo básico utilizando o comando print() para apresentar a mensagem “Olá, mundo!”, demonstrando uma das primeiras operações realizadas ao iniciar os estudos em Python.

Por fim, o projeto apresenta a utilização da função type() para identificar diferentes tipos de dados, como int, float, str e bool.

Esses exemplos proporcionam uma introdução aos principais conceitos da linguagem Python, ajudando no desenvolvimento da lógica de programação e na compreensão de entrada e saída de dados, variáveis, funções e tipos de dados.
