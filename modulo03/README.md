🐍 Projetos de Lógica de Programação - Python

Funcionalidades Principais

Os projetos foram desenvolvidos para praticar conceitos fundamentais da linguagem Python, utilizando programas simples executados pelo terminal.

Projetos disponíveis:

* Classificação de idade.
* Calculadora com menu de opções.
* Operações matemáticas básicas.
* Comparação entre dois números.
* Entrada e processamento de dados pelo usuário.
* Utilização de estruturas condicionais.
* Utilização de estruturas de repetição.
* Realização de operações matemáticas.
* Exibição de resultados no terminal.

⸻

Tecnologias e Estruturas Utilizadas

Linguagem

* Python 3

Funções utilizadas

* input() para receber dados do usuário.
* int() para converter valores para números inteiros.
* float() para converter valores para números decimais.
* print() para exibir informações e resultados.

Estruturas de programação

* Variáveis para armazenamento dos valores informados.
* Estruturas condicionais (if, elif, else).
* Estrutura de repetição (while).
* Operadores matemáticos (+, -, *, / e %).
* Operadores de comparação (>, < e ==).
* Entrada e saída de dados pelo terminal.
* Validação de opções escolhidas pelo usuário.

Panorama Geral: Projetos de Lógica em Python

Os projetos foram desenvolvidos com o objetivo de praticar conceitos básicos de lógica de programação utilizando Python, trabalhando com entrada de dados, processamento de informações e apresentação de resultados.

👤 1. Classificação de Idade

O primeiro projeto solicita a idade do usuário e classifica a pessoa de acordo com a faixa etária informada.

O programa utiliza estruturas condicionais para verificar a idade e apresentar uma das seguintes classificações:

* Criança.
* Adolescente.
* Adulto.
* Idoso.

Esse projeto trabalha principalmente com variáveis, conversão de dados, operadores de comparação e estruturas condicionais.

⸻

🧮 2. Calculadora com Menu

O segundo projeto apresenta um menu de opções para o usuário escolher entre:

* Soma.
* Subtração.
* Sair.

O programa utiliza um while para manter o menu funcionando até que o usuário escolha a opção de saída.

Para as operações matemáticas, são solicitados dois números e o resultado é apresentado no terminal. Caso seja digitada uma opção diferente das disponíveis, o sistema informa que a opção é inválida.

Esse projeto trabalha com estrutura de repetição, estruturas condicionais, entrada de dados e operações matemáticas.

⸻

🔢 3. Operações Matemáticas

O terceiro projeto solicita dois números inteiros e realiza diferentes operações matemáticas entre eles.

O programa apresenta:

* Soma.
* Diferença.
* Multiplicação.
* Divisão.
* Resto da divisão.

Esse projeto tem como objetivo praticar operações aritméticas, variáveis, entrada de dados e exibição de resultados.

⸻

📊 4. Comparação de Números

O quarto projeto solicita dois números inteiros e compara os valores informados.

O programa verifica se:

* O primeiro número é maior.
* O segundo número é maior.
* Os dois números são iguais.

Para realizar essa verificação, são utilizadas estruturas condicionais e operadores de comparação.

Esse projeto trabalha principalmente com if, elif, else, variáveis e operadores de comparação.

⸻
